Section 1 · Hands-on

Encoding Playground 🎮

Click an encoding method. Watch how the table transforms — the colour coding shows what each number represents. Notice the dummy variable trap warning for One-Hot!

🏷️
Label Encoding
Red→0 · Blue→1 · Green→2
Simple integers. Implies a false ordering — Red < Blue < Green.
Use for: target variable, ordinal data
🔢
One-Hot Encoding
Red:[1,0,0] Blue:[0,1,0]
Binary columns per category. No false order. Use drop_first=True!
Use for: nominal categories, low cardinality
📊
Ordinal Encoding
Low→1 · Mid→2 · High→3
Integer that reflects a real natural order you define explicitly.
Use for: education, ratings, satisfaction
Label Encoding
Integers assigned alphabetically
⚠️ Dummy Variable Trap: With 3 categories, you only need 2 columns — the third is always derivable from the other two. Use drop_first=True in pd.get_dummies() to avoid multicollinearity.
