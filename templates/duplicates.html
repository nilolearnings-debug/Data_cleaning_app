Section 3 · Techniques

4 Ways to Drop Duplicates

The keep= parameter is the most important choice — it determines which occurrence survives.

Full Row Duplicates
# Count total duplicates df.duplicated().sum() # Boolean mask of which rows are dups df.duplicated() # Keep first, remove rest (default) df.drop_duplicates() # Keep last occurrence df.drop_duplicates(keep='last') # Remove ALL copies of duplicates df.drop_duplicates(keep=False)
Subset / Partial Duplicates
# Same email = duplicate (ignore name) df.duplicated( subset=['email'] ).sum() # Drop by subset, keep first df.drop_duplicates( subset=['name', 'email'], keep='first' ) # Check missing after drop print(df.shape)
